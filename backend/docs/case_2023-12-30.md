## 9. 一个 claim 如何 trace 到 evidence

示例 claim：

```text
cell_1014600_1014610 属于已掘区段中可解释的 GRCI 关注 cell。
```

追溯路径：

```text
report claim
-> coupling_evidence.high_grci_cells
-> ConstructionStateCell
-> supporting_evidence_ids / source_trace
```

这说明报告中的 cell 级耦合判断可以回到结构化证据和原始证据线索。
