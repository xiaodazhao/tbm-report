# 项目文档索引

本目录用于存放项目级说明、全局审计、方法逻辑梳理和论文写作草稿。后端运行说明仍以 `backend/docs/` 为主；本目录主要服务于项目整体理解和论文材料组织。

## 当前文件

| 文件 | 用途 |
|---|---|
| `FULL_PROJECT_CODE_REVIEW.md` | 全项目代码审计与方法逻辑反向梳理，偏代码覆盖、调用关系、风险清单。 |
| `PROJECT_LOGIC_REVERSE_MAP.md` | 项目方法逻辑反向说明，偏“项目为什么这样设计、各环节怎么运转”。 |
| `paper/paper_draft_v2.md` | 论文草稿归档，避免根目录散落论文正文。 |

## 使用约定

- `backend/docs/`：后端方法、字段契约、运行方式、实验脚本说明。
- `experiments/`：实验脚本、实验说明和轻量结果索引；大体量输出目录默认不提交。
- `docs/`：项目总览、论文草稿、全局审计和跨模块解释。
- `_archive/` 与 `backend/_archive/`：旧版本代码和历史参考，不参与当前主流程。
